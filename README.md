# Practical-ML

This repository contains an exploratory data analysis notebook for the coupon acceptance assignment in the UC-B course module.

## Project Objective

The goal of this project is to analyze customer behavior and identify the factors that influence whether a driver accepts a coupon. The notebook uses the coupon dataset to explore patterns in acceptance rates, compare different customer segments, and visualize the results with Python libraries such as pandas, seaborn, and matplotlib.

## What is included

- A Jupyter notebook that loads and explores the coupon dataset
- Data cleaning and missing-value checks
- Visualizations of coupon distribution and temperature patterns
- Analysis of bar coupon acceptance across different demographic and behavioral factors
- A final section with hypotheses about which customer groups are more likely to accept coupons
